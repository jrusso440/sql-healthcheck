# Russo SQL Health Check — Vite + React + Tailwind

Personalized landing page for John Russo's SQL optimization service.

## Customize
- Edit contact details in `src/App.jsx` (EMAIL, PHONE, BRAND).
- Replace the monogram logo at `src/assets/logo.svg` with your own.
- Update pricing or package copy in the `Packages()` component.

## Run & Deploy
```bash
npm install
npm run dev
npm run build
npm run deploy
```

**GitHub Pages:** Set `homepage` in `package.json` and ensure `base` in `vite.config.js` matches your repository name.
